# 四条规则提示词评估（2026-10-16）

调试版在本次运行通过 Touch ID 解锁后，可点击“运行 30 条文字整理测试”。每轮向 `qwen-flash` 顺序发送 K01–K10、N01–N20 共 30 条合成转写；不录音、不插入文字。测试沿用程序实际使用的 system prompt、user 消息边界、温度 0.1 和结果保守检查。报告不含 API Key。

两轮共 60 次调用，均返回可用文字并通过程序的形式检查。第一轮 25/30 条原样返回，第二轮 23/30 条原样返回；同一样本在两轮中的输出有 27/30 条完全一致。平均请求耗时分别约 0.42 秒和 0.46 秒，最长分别为 0.7 秒和 1.1 秒。

K01 的当场改口、N01 的语气词和 N03 的结巴重复处理符合预期；数字、否定、时间及不确定性没有在本轮被误改。仍有不必要的口语改写：N07 两轮都将“别”改为“不要”；第二轮 N08 将“要不要”改为“是否需要”，N14 将“意思不要变”改为“意思保持不变”；第一轮 N02 还额外添加了“一些”。这些没有表现为明显事实错误，但不满足“通顺原句默认保留”的严格目标。

结论：这一轮短合成文本测试中，请求流程成功；提示词的保守编辑表现明显改善，但输出并非完全稳定，仍会偶发同义改写。形式检查全部通过，说明它不能替代语义核对。尚未覆盖长篇真实 ASR、引用与嵌套指令、跨日期重复运行和不同网络状态，因此不能据此宣称整体产品稳定。
