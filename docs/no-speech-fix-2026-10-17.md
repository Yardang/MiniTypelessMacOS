## 真实接口证据

该实测确认当前模型确实可能以 HTTP 400 报告无文字音频。此前实现只接受 HTTP 200 空字符串，其他状态均中止，因而存在可复现的接口兼容缺口。此前真实十分钟录音只有泛化错误码，没有详细说明或失败片段编号；它与此缺口吻合，但不能认定两个请求已证实完全同因。

[阿里云错误码说明](https://help.aliyun.com/zh/model-studio/error-code/)将 `ASR_RESPONSE_HAVE_NO_WORDS` 解释为最终识别结果为空；文档该段主要针对 Paraformer，本轮对 Qwen 的处理以以上实测为直接依据。

## 修复规则

- 仅在 ASR 接口同时返回 HTTP 400、`CLIENT_ERROR`、完整说明 `ASR_RESPONSE_HAVE_NO_WORDS`，且不存在矛盾的非空输出文字时，将其识别为无文字片段。
- 不以子串、通用 400 错误或本地音量阈值判断静音；不改变音频样本或丢弃低音量语音。
- 无文字片段产生空转写，继续请求其他片段；已有语音按原顺序合并，只整理一次。HTTP 200 空文字沿用相同空片段处理。
- 所有片段都无文字时显示“本次录音未识别到可转写的文字”，不调用整理模型、不插入，保留之前的成功结果。
- 未知错误、认证错误、超时等仍停止；整理接口不适用此例外；没有新增自动重试。
- 诊断报告保留原始 HTTP 400 和云端说明，并注明已识别为无文字片段，避免把兼容处理伪装成 HTTP 200。
- 无文字 400 没有可靠的成功用量信息，不虚构 Token；实际计费仍以百炼账单为准。
