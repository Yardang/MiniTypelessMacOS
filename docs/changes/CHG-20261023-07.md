# CHG-20261023-07 — 修复 macOS 26 图标套框

状态：开发完成，安装后系统图标渲染验证通过；用户运行中的 Dock 复看待验。关联 MT-UI-005。

Preview 6 用户实机截图确认：深色图稿被缩小放进系统追加的浅色圆角底板。不是期望设计，未发现与屏幕分辨率有关的证据。旧式 ICNS 的系统合成行为与生成图的透明留白共同影响最终观感；仅校验图标资源及其缩略图不足以验收 Dock。

保持选定 A 图稿和三个不对称波形，采用适合当前 macOS 的原生图标资源打包方式并检查系统渲染。不得通过更改全局 Dock 设置、重启 Dock、退出当前录音程序或修改钥匙串来修复。

验收：系统渲染不再出现浅色大底板包裹小深色图标；常用尺寸清晰，身份及核心功能不变；独立交付以保留回退。构建、系统渲染检查、用户 Dock 复看分别记录。

## 实现

- 新增 `AppIcon.icon` 原生 Icon Composer 文档，保留选定 PNG 字节，调整图层比例 1.03 / 垂直位置 6 pt 以匹配系统遮罩；关闭额外图层高光、阴影和玻璃效果，避免叠加改变原稿。
- Xcode 通过 `ASSETCATALOG_COMPILER_APPICON_NAME` 编译原生 `Assets.car`，同时生成旧系统 fallback ICNS 和 CFBundleIconName 元数据。移除手工 ICNS 打包脚本/资源，防止再次绕过原生图标流程。
- 保留 Info.plist 引用、bundle ID、签名/钥匙串身份及应用内符号。仅更新 build 标识至 `2026-10-23-glass-7`，不改录音和窗口逻辑。

## 验证与边界

- 使用 NSWorkspace.icon(forFile:) 读取 Preview 6 并渲染 256 px 图标，复现用户所见的浅色外框与缩小深色内图；不是只用原 PNG 代替系统合成。
- 同一方法读取构建产物和已安装 Preview 7，均确认无浅色套框；深色底板占据系统标准圆角区域，四周正常透明留白仍保留。
- [修复前系统渲染](../assets/icon-system-before.png) / [修复后系统渲染](../assets/icon-system-after.png)。这些只含应用图标，不含用户桌面或内容。
- Debug/Release 构建通过，验证产物 Assets.car、fallback ICNS、CFBundleIconFile/CFBundleIconName。签名严格验证通过，entitlements 与 Preview 6 完全一致。
- 系统图标服务检查不等同于运行中 Dock 已刷新；未启动新版、未清图标缓存、未重启 Dock 或退出现用程序。旧系统 fallback 已生成但未在旧 macOS 实测；核心功能离线/实机测试继承之前版本，无需重复。
