# CHG-20261025-04 — B3 Short 图标统一替换

状态：开发完成；菜单图形专项、Debug/Release 构建、签名与系统图标检查通过；新版实机待验。关联 MT-UI-005、MT-UI-007。基线 64847ac；独立分支 ui/b3-short-icon-20261025。

## 已确认设计与范围

用户确认 B3 Short 金属玻璃 Dock 预览及单色菜单栏预览，授权统一替换。三个不等高波峰、两个深谷；第三个波峰直接收束到短横线，再接竖直带点的小写 i，末端不增加凹槽/小波峰。Dock 保留蓝灰金属玻璃与完整银边；菜单栏去掉底板，系统模板自动适配浅深前景。窗口内符号、状态文字、菜单交互和核心功能不改。

## 可观察验收与验证计划

1. Dock 与菜单栏均为 B3 Short，区别于旧版两段宽波；短横线、竖直 i 和圆点清楚。
2. 原生图标资源打包；系统渲染 32/64/256 px 检查完整银边和留白，避免上轮裁切或过小套框。
3. 菜单栏离屏专项检查浅/深模板、透明底与无裁切；检查小尺寸波峰和圆点。
4. Debug/Release 编译、签名和钥匙串权限身份核对；独立安装新应用，保留旧版，不退出或启动用户应用。
5. 实现、自动检查、用户实机验收分开记录；最后仅需用户切换后观察两个图标。

## 来源与回退

Dock 取自用户确认的 B3 Short 预览，使用 image_gen 提取生产图，保存入 artwork；菜单栏以对应轮廓实现自有矢量。原始设计预览与生产源图均归档。现用 Menu Bar Preview（build 2026-10-25-menu-icon-1）保留作为回退。原素材与代码可从 64847ac 恢复。此轮不推送、不合并。
