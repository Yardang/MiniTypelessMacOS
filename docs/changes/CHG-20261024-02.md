# CHG-20261024-02 — 通用输入框与主动粘贴

状态：开发完成；自动化与构建通过，新增目标实机待验。关联 MT-INS-003/004。基线 4a16e1b；独立副本与分支 feature/universal-insertion-20261024，不修改 UI 开发目录。

用户授权扩大到 Safari（X/Grok、Claude 网页）、Claude 桌面快捷窗口、微信等普通输入框。取消应用白名单，仍要求输入框/光标两次一致、目标及交互未变化；不自动发送。不保证所有网站或控件支持辅助功能。

主动备用：Control+Option+Command+V 或现有兼容粘贴入口。仅本次完成结果可用；已识别的密码/非文本/歧义目标拒绝；仅焦点信息缺失时允许主动请求一次粘贴。自动无焦点兼容仍仅 Codex/ChatGPT，默认关闭。快捷键注册失败可用原菜单，不替换其他程序快捷键。

验收：AC-INS-01 非名单应用进入焦点检查；AC-INS-02 密码/非文本/切应用/取消禁止粘贴；AC-INS-03 主动无信息备用与自动模式严格分开；AC-INS-04 当前失败/录音处理中不可粘贴旧结果；AC-INS-05 Safari 两网页、Claude 快捷窗口、微信真实短句需用户验收。离线测试与编译不代表真实目标已接收。

同一应用内切换页面/对话仍可能改变接收位置，用户须保持目标；本轮不读取网页内容或记录口述文字。保留 UI、模型、钥匙串、网络与旧程序。

## 实现与验证

- 普通自动插入取消应用名称名单；仍执行目标路由、两次输入框/选择范围核对及交互变化检查。不扩大自动无焦点兼容应用。
- 优先遍历实际获得焦点的网页/容器，兼容未提供 AXFocusedWindow 的快捷窗口；明确按钮直接拒绝，密码子控件拒绝。查询限时/节点超限不再落入无焦点兼容，避免未查完就粘贴。Electron 辅助功能激活只保留给原四个应用。
- 新的 Carbon 全局快捷键 ⌃⌥⌘V；等待用户松开修饰键后再检查目标，期间换应用或其他键鼠输入取消。仅本次成功完整结果可用，不粘贴失败后旧文字；原 2 秒入口复用同一检查流程。已知不适合的目标不能通过手动请求绕过。
- 剪贴板准备后再检查操作代次、交互和目标；仍仅发送 Command-V、不会发送 Return。尊重原剪贴板恢复策略。
- `scripts/test.sh` 八组离线回归全部通过（日志 `/tmp/minitypeless-universal-tests-final.log`）；覆盖新增应用路由、无主窗焦点树、密码/按钮、无信息兼容与超时/权限拒绝，以及原有睡眠、取消、迟到响应、结果归属、36 组布局和 HUD。
- Debug 开发签名构建和 Release 无签名编译通过；初次受沙盒签名/图标服务限制，允许本机构建服务后通过。未请求云端、未使用真实录音/文字或 API 密钥。
- 实机尚未验证：快捷键注册/冲突及真实粘贴、Safari 的 X/Grok 与 Claude 网页、Claude 桌面快捷窗口、微信。不能将自动测试等同于这些场景通过。部分网页子进程或非标准编辑器仍可能无法提供可用焦点；失败留结果供复制。
