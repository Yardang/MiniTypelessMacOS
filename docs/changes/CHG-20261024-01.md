# CHG-20261024-01 — 失败提示自动消失

状态：开发完成，离线回归与构建通过；2026-10-24 用户确认 Preview 8 未插入、失败、成功三种情况均稳定运行，三类结果提示实机验收通过。关联 MT-UI-003、MT-UI-002。

用户报告“文字已生成，未插入”胶囊一直浮在前端、无法拖动，阻碍操作。采用与成功提示一致的 3 秒自动隐藏，不增加必须点击的操作或全局鼠标监听。保留右侧查看按钮、菜单栏/程序坞重新打开结果的路径；隐藏只影响提示，不清除文字、音频或错误状态，不触发重试。

范围：HUD 提示时序。录音、转写、整理进行中仍持续显示；等待唤醒逻辑不变。未插入、失败、取消、未解锁和独立录音启动失败通知自动隐藏。同一状态刷新不重复弹出，新阶段取消旧倒计时。

验收：未插入提示最初可见，约 3 秒后隐藏；结果仍可复制；同一状态刷新不重现；新录音/处理不被旧倒计时隐藏；独立 notice 同样自动隐藏。用合成状态做离线回归，保持透明测试窗口以免干扰用户桌面。构建、自动测试与真实使用反馈分开记录。

分支 `fix/hud-dismiss-20261024` 从已交付 Preview 7（a109d32）继续，因为前轮 UI 尚未合入 main；不丢失已选界面和图标，不擅自合并、删除分支或推送。
