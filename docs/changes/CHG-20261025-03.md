# CHG-20261025-03 — 菜单栏自有符号与系统黑白适配

状态：开发、浅深外观离屏检查、Debug/Release 构建与签名验证通过；用户实际菜单栏验收待确认。关联 MT-UI-007。基线 83df3a6；独立分支 ui/menu-bar-icon-20261025。

## 已确认的需求

菜单栏用已选定图标的单色“声波连接竖直小写 i”，无玻璃底板；让系统根据菜单栏外观绘制浅色/深色，不固定白色。取消菜单栏按阶段自定义着色，录音/处理/失败仍通过 HUD 与提示文字反馈。Dock 图标、窗口内功能图标、菜单项及点击行为保持原样。

现有来源是 NSImage(systemSymbolName: "waveform")，刷新时指定 QuietStyle 状态色，但未明确标记模板。代码未指定黑色；截图黑色的具体运行时成因未单独复现，不将其说成已确定根因。本次直接采用原生模板路径和自有图形。

## 来源与边界

菜单栏新符号以已验收的自有图稿为形状参考，用独立矢量路径表达；不用 Apple waveform 或其导出图。Apple Xcode and Apple SDKs Agreement 2.10 允许按条件使用系统图像，但限制 app icon/logo/trademark 用途；本次替换不等于完成商标检索或作法律保证。参考 https://www.apple.com/legal/sla/docs/xcode.pdf 。本机 NSStatusBarButton.h 明确模板图像按菜单栏外观适配；NSButton.h 说明 contentTintColor=nil 为无自定义着色。

## 验收计划

1. 菜单栏显示无底板的波浪+i，圆点与竖线在小尺寸清晰，四周不裁切。
2. 模板标志为 true、无自定义 tint；系统浅/深外观绘制分别有适当反差，状态更新不再次着色。
3. 原四项菜单和提示文字保留；主窗、HUD、Dock 原样。针对性离屏图形检查与 Debug/Release 编译、签名验证。
4. 独立安装，保留 Wave i Fit/Quick Copy 与钥匙串；不退出现用程序。用户只需切换后看菜单栏颜色及打开菜单，不重复核心全套实测。

## 实施与验证

- 新增 MenuBarIcon.swift 独立绘图职责；24×18 pt 原始矢量波浪接竖直 i，isTemplate=true，提供辅助功能名称。黑色路径只是模板透明度遮罩，不指定最终菜单栏颜色。
- 菜单栏改为内容自适应宽度，避免宽符号被方形按钮裁切。contentTintColor=nil，删除 refreshPresentation 状态色覆盖；tooltip 与原四项菜单未改。
- MenuBarIconRegression 使用生产矢量图与离屏无边框 NSButton，验证模板、透明底、无边缘裁切，以及 Aqua/Dark Aqua 像素亮度分别为 0.0/1.0（黑/白）；[浅色图](../assets/menu-icon-light.png)、[深色图](../assets/menu-icon-dark.png)。未创建可见菜单栏项或显示窗口，未改剪贴板。此项不是用户壁纸/菜单栏材质的实机验收；状态刷新不再着色由代码差异核查确认。
- Debug/Release 开发签名构建通过，日志在 BuildArtifacts/menu-icon-debug.log 和 menu-icon-release.log；专项测试在 BuildArtifacts/menu-icon-tests。继承核心功能回归，未重跑八组套件。
- 严格签名通过，钥匙串 entitlements 与 designated requirement 和 Wave i Fit 一致；bundle ID 仍为 com.minitypeless.app。Dock 原图/配置无差异；新旧 32/64/256 px 系统渲染 PNG 字节相同。Assets.car 重编译后容器字节不同，不以容器哈希判断视觉差异。
- 独立安装 `02 Mini Typeless Application/Mini Typeless Menu Bar Preview.app`，build `2026-10-25-menu-icon-1`，可执行文件 SHA-256 `d98bc29711ac8115cc69107bbdb500bbc2fe318870ca9a38530127459006fbcf`；安装后签名再次通过。Wave i Fit 保持 `6a3787fecd85bca3ad1d19bea5e7c4ed04522ba0319de0212091dc6403808503`，其他旧版保留。不启动新版、不退出现用程序，不修改系统主题。
