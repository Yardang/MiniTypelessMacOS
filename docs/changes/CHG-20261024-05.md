用户在微信仍未能插入，希望“文字已生成，未插入”的胶囊按钮从查看改为复制。本轮只改失败后的取回路径，不宣称修复微信自动插入。

开发目录位于用户指定的 01 Mini Typeless Development，独立 Git 工作目录 MiniTypeless-Feature 共享原仓库与功能分支，避免切换 UI 目录。安装文件仅放 02 Mini Typeless Application。Quick Window Fix 迁移后可用已由用户确认，旧版保留。
