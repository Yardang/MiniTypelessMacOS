# CHG-20261025-02 — 校准新图标的边缘与留白

状态：开发、Debug/Release 构建、签名及实际系统图标检查通过；用户运行中 Dock 复看待验。关联 MT-UI-005；基线 dba3496。

## 问题与范围

用户实际 Dock 截图确认：Wave i 版本的银色外缘比选定图稿弱、波形贴边。此前检查只覆盖无额外套框与符号清晰，未充分核对外缘保真。生产图自身占画布比例已变，沿用旧图层 1.03 / 向下 6 pt 造成原生遮罩裁去银边；不是屏幕分辨率兼容故障。此前 Preview 6 的小图套框是另一个旧式打包问题。

保留 PNG 字节，只调原生图标图层的缩放与位置。菜单栏图标和所有功能代码仍不改。旧版独立保留。

## 验收与实施

原生 Icon Composer 预览对比 0.84、0.87、0.90，选择 0.84、偏移 [0,0]，保留四边玻璃高光与符号留白。需进一步用编译产物的 NSWorkspace 系统图标检查 32/64/256 px，确认无额外套框；开发签名与钥匙串身份须与前版一致。

以后每次换图稿，必须重新检查主体占画布比例、四边高光是否被裁、符号留白，以及实际系统小尺寸渲染；不只检查清晰度与无套框。该检查不等于用户运行中 Dock 验收。
