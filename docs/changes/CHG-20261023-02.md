# CHG-20261023-02 — 降低灰雾感，改用通透玻璃

状态：开发完成，实际使用待验。关联 MT-UI-003/004。

用户在运行 UI Preview 后确认布局好看，但截图中背景过灰、几乎看不见下一层；明确希望更通透的玻璃。本轮更换结果窗与录音胶囊的背景材质，并按用户追加要求提供浅色、深色、跟随系统三种外观。默认跟随系统，本机保存选择；浅色保留原配色，深色使用深玻璃和浅文字。录音和插入流程不变。

macOS 26 起使用 NSGlassEffectView 的 regular 自适应玻璃样式及随外观切换的轻微 tint；内容放在系统指定的 contentView 内，文字和按钮保持不透明。旧系统保留原生磨砂兼容路径。尊重系统减少透明度设置，不修改系统偏好，不用私有模糊接口或整窗透明度。

验收：玻璃能够透出下层颜色和轮廓；正文和按钮可读；原有布局、胶囊非激活行为和窗口重开保持。验证范围包括布局及窗口稳定性回归、Debug/Release 编译；实际背景合成不以离屏截图作为验收证据。无需重复云端/断网/十分钟录音测试。

追加依据：用户确认浅色桌面效果好看，系统当前使用深色模式；白色磨砂在黑底上显灰。因此保留浅色布局，优先适配深色，而非强制所有背景使用白色材质。

## 取舍与验证

- 试验 clear 样式后发现混合深浅背景上对比不足，最终采用 regular 玻璃：保留下层色彩与轮廓，同时由系统调节背景对比。深色使用浅色正文、柔和浅蓝操作与深色 tint；浅色保留原灰蓝配色。系统外观通过继承机制响应，不修改系统设置，不读取背景截图来决定主题。
- 设置新增“外观”：跟随系统（默认）、浅色、深色；选择立即应用到结果窗、胶囊及已打开的设置/帮助窗口，仅将枚举值保存在本机 UserDefaults。
- 36 个原生窗口布局检查通过（原 12 组 × 三种外观），临时偏好库测试默认值/保存恢复通过，设置入口三项可达；窗口 25 次关闭重开回归通过。Debug 签名构建与 Release 无签名编译通过。
- 在完全由合成内容覆盖的测试区域检查了系统合成后的浅/深玻璃：能辨认下层明暗分区与模糊色带，两种主题文字可读。此检查不同于不含背景合成的离屏位图；不代表用户的所有桌面或真实输入焦点均已验收。
- 本机只读确认减少透明度、增强对比度均关闭。程序仍尊重系统辅助功能设置。
- 继承上一轮七组离线核心回归及 10 月 21 日实机结论，本次不重复云端、断网或长录音测试；旧系统兼容路径已编译，未在旧系统实测。
