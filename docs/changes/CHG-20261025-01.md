# CHG-20261025-01 — 声音转文字图标

状态：开发、构建、签名及系统图标渲染检查完成；用户实际 Dock 复看待验。关联 MT-UI-005。

## 范围与基线

用户选定深蓝灰玻璃底、左侧不对称声波接右侧竖直小写 i，底部紧凑圆角，圆点对齐竖线；用于 Dock/Finder 应用图标。原稿确认于 10 月 24 日，10 月 25 日授权接入。

从 feature/universal-insertion-20261024 的 c9c8e8a 建立 ui/wave-i-icon-20261025，继承 Claude 快捷窗口修复与已验收的未插入快捷复制。原主目录开始时位于 fix/hud-dismiss-20261024 (a8ffc17)，该旧功能基线不用于新应用。另一工作目录及其分支不改动。

仅更换图稿、诊断版本号与文档；保留原生 Icon Composer 打包、bundle ID、签名及钥匙串。主窗/菜单栏/HUD 中的声波不在本次范围。菜单栏小标的来源、许可与系统颜色适配登记为后续独立事项，未作法律结论。

## 验收条件

- Dock/Finder 显示选定波浪接竖直 i，无预览板标题、白色背景或额外套框；小尺寸仍可区分圆点和竖线。
- Debug/Release 可构建，原生 Assets.car 与 fallback ICNS 存在，签名及钥匙串身份与 Quick Copy 一致。
- 独立安装在 02 Mini Typeless Application，保留 Quick Copy 及全部旧版；不自动退出或启动用户应用。
- 用户只需自然切换后复看 Dock；录音、睡眠、网络、复制和插入不受资源变更影响，继承已有验收，不重复全套实测。

- 使用内置 image_gen 从已确认预览提取透明背景生产图稿；确认稿与生产图均保存在 artwork，生产图与 AppIcon.icon/Assets/Approved.png 字节相同。图稿是烘焙玻璃效果；不是实时桌面模糊。生成提示词和来源见 artwork/README.md。
- 沿用原生图标资源和图层 1.03 / 6 pt 配置；不使用旧式仅 ICNS 路径。仅 DiagnosticLog.build 改为 `2026-10-25-wave-i-icon-1`，其他 Swift 源码与 c9c8e8a 无差异。
- Debug / Release 开发签名构建均通过；Assets.car、fallback AppIcon.icns 与 CFBundleIconName 齐全。日志在 `01 Mini Typeless Development/BuildArtifacts/wave-i-debug.log` 与 `wave-i-release.log`。
- 严格签名检查通过；Debug/Release 的 entitlements 与 designated requirement 和已验收 Quick Copy 完全一致，bundle ID 仍为 com.minitypeless.app。最初受限环境报告 CSSMERR_TP_NOT_TRUSTED（旧版也同样报告），通过系统信任服务重查后三者均通过；没有修改证书或钥匙串。
- 通过 NSWorkspace.icon(forFile:) 读取真实构建产物；绝对路径检查的 32/64/256 px 均能辨认波形与 i，无额外浅色套框。证据：[256 px](../assets/wave-i-system-256.png)、[64 px](../assets/wave-i-system-64.png)、[32 px](../assets/wave-i-system-32.png)。验证脚本与身份比对记录在 BuildArtifacts/wave-i-verification。系统渲染不等同于运行中 Dock 已刷新。
- 未改录音、网络、复制、输入焦点及睡眠逻辑；继承 Quick Copy 与此前验收，不重跑无关核心回归、不增加镜像实现测试。
