# Mini Typeless 产品需求（PRD）

版本：0.2（2026-10-21 三项实机验收已验证）；更新：2026-10-23（UI 迭代开发完成，实机待验）。此文件是代码仓库内的需求入口；每次功能变更更新对应编号和变更索引。历史修复文档保留当时事实，冲突时以本文件最新生效规则为准。实现、自动测试通过和实机验收是不同状态。

## 目标与范围

面向 macOS Apple Silicon 的自用中文语音输入工具：Fn 开始 → Fn 停止（或 10 分钟到期）→ ASR 转写 → 忠实轻量整理 → 尝试插入输入框；不会自动发送消息。优先保证连续使用、结果可找回、失败有解释。

第一阶段不做方言/老人微信输入、翻译、风格学习、半自动邮件、商业发布。这些来自早期讨论的想法进入后续规划，不能顺手加入本轮。

来源：此前“02 MVP: 复刻 Typeless 方案（项目文档维护）”的初始需求、当前会话已确认的规则、现有源码/README/测试。本轮在项目目录中未找到原始 PRD 文件；本文件是有明确来源的基线整理，不冒称找到了原稿。

## 状态与本轮验收条件

| 场景/编号 | 期望结果 | 验证方式 |
| --- | --- | --- |
| AC-SLP-01 空闲睡眠/唤醒 | App 不退出，已解锁状态保留，Fn 可以开始；退出后重启仍要解锁 | 自动化 + 一次实机睡眠 |
| AC-SLP-02 录音时睡眠 | WAV 完整落盘，无上传，记录待唤醒处理状态 | 注入录音设备/睡眠通知；实机短句 |
| AC-SLP-03 唤醒及重复通知 | 仅一次自动转写；原有目标校验仍生效，不能保证自动插入锁屏/错误目标 | 假网络请求计数 + 实机观察 |
| AC-SLP-04 10 分钟与睡眠/设备回调竞争 | 只结束/处理一次；睡眠时不上传；旧回调不影响新段 | 模拟计时器及旧回调 |
| AC-SLP-05 处理时睡眠 | ASR/整理阶段均取消，迟到响应不改结果；唤醒不自动重发 | 自动化 |
| AC-REC-01 替换待重试录音 | Fn 可开始下一段；成功后旧文件清除，恢复按钮消失，保留上次成功文字 | 集成回归 |
| AC-REC-02 新录音启动失败 | 麦克风拒绝、设备创建/启动失败均保留旧段，仍可重试/导出 | 自动化 |
| AC-REC-03 取消/退出/新录音抢先 | 删除/退出/成功替换清除待唤醒任务；旧唤醒或异步响应不会上传旧段/覆盖新结果 | 自动化 |
| AC-SEC-01 首次未解锁 | Fn 提示先解锁，无录音/上传；取消 Touch ID 不丢旧段 | 自动化逻辑 + 沿用真实钥匙串流程 |

“10 分钟”是单段实际录音上限；真正睡眠会结束该段，不将睡眠时间记为录音，不拼接唤醒后的另一段。关屏与系统睡眠不同，不能用熄屏代替实机睡眠验收。

## 安全、数据与体验取舍

- 同一次运行跨睡眠保留内存中的会话密钥，提升唤醒后的连续使用体验；退出后仍清除。系统解锁保护设备，应用不绕过系统锁屏。钥匙串项目及 Touch ID 访问控制不改。
- 唤醒自动处理只针对因睡眠而结束、尚未上传的录音；已经提交过的失败/中断请求不自动重试，避免重复费用和意外插入。
- 下一次成功录音会自动舍弃旧的待重试音频；需要留存时应在新录音前另存。原有最新成功文字不因开始新录音而清空。
- 目前无跨启动音频/文字恢复；本地日志只用于诊断，不能恢复口述内容。
